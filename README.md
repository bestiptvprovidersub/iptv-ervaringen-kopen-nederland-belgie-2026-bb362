## 🛠️ Aanbevolen Hardware & Optimalisatie



### Belangrijkste Specificaties voor Optimale Weergave:
- **Netwerkverbinding**: Bekabeld Ethernet (Cat6) aanbevolen boven 5GHz Wi-Fi ter voorkoming van jitter.
- **Aanbevolen Apps**: TiviMate IPTV Player, IPTV Smarters Pro, Smart IPTV, of Formuler MyTVOnline 3.
- **Buffer Instellingen**: Buffergrootte instellen op 3 tot 5 seconden voor live sportuitzendingen in 4K UHD.
- **DNS Optimalisatie**: Gebruik Cloudflare DNS (1.1.1.1) of Google DNS (8.8.8.8) voor de laagste routing latency naar Europese content delivery networks.
